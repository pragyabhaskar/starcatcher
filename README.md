
# ⭐ Star Catcher

A simple browser-based arcade game built using HTML, CSS and JavaScript.

## 🎮 About the Game

Catch falling stars using your spaceship and score as many points as possible before time runs out!

## 🕹️ Controls

- Left Arrow (←): Move left
- Right Arrow (→): Move right
- A / D: Alternative movement controls

## ✨ Features

- Simple spaceship movement
- Randomly generated falling stars
- Collision detection
- Score tracking
- 60-second game timer
- Restart functionality

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API

## 🚀 How to Play

Open `index.html` in a web browser.

Alternatively, play online using GitHub Pages.
